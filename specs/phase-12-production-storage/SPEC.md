# Phase 12 Spec: 生产级存储适配

## 目标

将当前本地存储实现抽象为可替换后端，为更大规模、并发访问和服务化部署做准备。

## 建议范围

- 为文档、向量和图谱存储定义稳定协议。
- 保留 SQLite/ChromaDB/NetworkX 作为默认本地后端。
- 优先评估 PostgreSQL + pgvector；图谱后端评估 Neo4j。
- 增加迁移、备份、恢复和一致性检查工具。
- 明确事务边界，避免文档元数据、向量和图谱部分写入。

## 验收标准

- Orchestrator 不依赖具体存储实现的私有字段。
- 至少一个外部存储后端通过契约测试。
- 摄入失败时可回滚或可靠重试。
- 本地后端仍可零配置运行。

## 前置条件

Phase 9 质量门禁完成；建议在 Phase 11 状态模型稳定后实施。
