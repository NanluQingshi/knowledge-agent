# Spec 索引

本目录用于记录后续迭代的范围、验收标准和执行进度。每个实现方向使用独立目录，
并至少包含：

- `SPEC.md`: 目标、范围、设计和验收标准
- `PROGRESS.md`: 执行记录、验证结果和未完成事项

## 实现顺序

| 顺序 | 目录 | 主题 | 状态 |
|---|---|---|---|
| 1 | `phase-09-quality-gates/` | 主线稳定性与 CI 质量门禁 | 实现完成，验收暂缓 |
| 2 | `phase-10-container-deployment/` | Docker 与本地部署 | 规划中 |
| 3 | `phase-11-workflow-orchestration/` | 可恢复的工作流编排 | 规划中 |
| 4 | `phase-12-production-storage/` | 生产级存储适配 | 规划中 |

## 执行约定

1. 开始实现前先确认对应 `SPEC.md` 的范围和验收标准。
2. 实现过程中持续更新同目录下的 `PROGRESS.md`。
3. 发现新方向时新增独立目录，不直接扩大当前 Phase 的范围。
4. 完成后将验证命令、结果和遗留风险写入进度文档。
